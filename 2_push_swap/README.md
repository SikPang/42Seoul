# push_swap

## 1. 프로젝트 설명

정수 목록을 두 스택 A·B의 제한된 연산만으로 정렬하고, 필요한 연산 명령을 표준 출력에 출력하는 프로젝트다. 자료구조 구현과 정렬 전략을 결합해 명령 시퀀스를 생성한다.

<br/>

## 2. 사용 기술 및 학습 범위

**핵심 CS**: 자료구조와 정렬 알고리즘 — 스택·큐·원형 덱, 기수 정렬과 순위 정규화, 제한된 연산의 명령 수 최적화.

- C, Makefile, 직접 구현한 큐·원형 덱·동적 배열
- 입력 파싱, 정수 변환, 중복 검사
- 기수 정렬, 순위 정규화, 3진수 분할
- 스택 연산의 추상화와 명령 목록 후처리

<br/>

## 3. 핵심 기술 및 설계

1. **입력 수집**: 인자별로 공백을 분리해 연결 큐에 저장한다. 이미 오름차순이면 명령 없이 종료한다.
2. **순위 정규화**: 양수·음수를 나눠 10진 기수 정렬로 정렬된 기준 배열을 만들고, 각 값을 순위로 치환한다.
3. **크기별 전략**: 작은 입력은 `mini_sort`와 `small_sort`로 처리한다. 큰 입력은 순위를 3진 문자열로 바꾸고, 자릿수별로 두 덱의 이동·회전을 조합한다.
4. **명령 수집**: `sa`, `pa`, `ra` 등의 연산을 큐에 기록한다. 후처리에서는 연속된 `pb`·`pa` 쌍을 제거한 뒤 출력한다.

큰 입력의 스택은 원형 배열 덱으로 표현해 앞·뒤 이동을 수행한다. 명령 생성과 출력은 별도로 관리한다.

구현 근거: [입력·정규화](main.c), [10진 기수 정렬](sort/radix_sort.c), [3진 분할 정렬](sort/main_sort.c), [진법 설정](utility/utility.h), [명령 후처리](command_util.c).

<br/>

## 4. 프로그램 실행법

C 컴파일러와 `make`가 있는 Unix 계열 환경에서 실행한다.

```sh
cd 2_push_swap
make
./push_swap 3 2 1
./push_swap "6 2 5 1 4 3"
./push_swap 6 2 5 1 4 3 > operations.txt
wc -l operations.txt
```

출력은 정렬된 숫자 목록이 아니라 한 줄에 하나씩 기록된 스택 명령이다. 오름차순 입력은 출력 없이 종료하고, 감지한 잘못된 입력은 표준 오류에 `Error`를 출력한다.

`get_args.cpp`는 무작위 입력 생성용 보조 소스이며 기본 Makefile의 빌드 대상은 아니다.

<br/>

## 5. 구현 범위

### 구현된 기능

- 여러 인자와 공백으로 묶인 정수 입력
- 숫자 변환 검사 및 정렬된 기준 배열의 중복 검사
- 작은 입력을 위한 별도 정렬 분기
- 순위 정규화와 3진수 기반 자릿수 처리
- 두 스택의 swap·push·rotate·reverse rotate 연산
- 생성 명령 저장·출력과 연속 `pb`·`pa` 제거



### 현재 구현의 제한

- 명령을 읽어 정렬 결과를 검사하는 별도 `checker` 프로그램은 없다.
- 최적 명령 수를 보장하는 알고리즘은 아니다.
- `small_sort`는 마지막에 B에 두 값이 있다고 가정한다. 4개 입력 경로와 `INT_MIN`의 음수 분리 경로는 추가 점검이 필요하다.
- 명령 최적화도 삭제 대상이 큐의 맨 앞에 있는 경우를 포함해 별도 경계 검증이 필요하다.
